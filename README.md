# La Grande Muraille de Chine

Reservation-only TastyIgniter site for La Grande Muraille de Chine (Spa), deployed on OVH shared hosting by Git. OVH clones this repository as-is: `vendor/` and the published public assets are already in Git. There is no Composer, SSH or shell Artisan step on the server.

The web docroot is `nouveau/public`.

See `docs/OVH.md` for the one-time installer. No passwords, API keys or installer token are stored in this repository.
